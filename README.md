# Raika Personalizados

[![Página inicial do site da Raika Personalizados](./img/site-preview.png)](https://natanashi.github.io/raika-personalizados/)

Site desenvolvido para a **Raika Personalizados**, uma empresa que produz materiais personalizados para festas, eventos e empresas.

## Sobre o trabalho

Desenvolvi este projeto para apresentar de forma clara a identidade, os serviços e o portfólio da empresa. A Raika trabalha com cartões, topos de bolo, painéis para festas, lembrancinhas, adesivos, etiquetas, embalagens e outros produtos feitos sob encomenda.

O site foi planejado para funcionar bem no computador e no celular, facilitar a visualização dos produtos e deixar os caminhos de contato e orçamento sempre acessíveis. O projeto representa uma experiência profissional de criação web voltada às necessidades reais de uma empresa.

## Principais objetivos

- Apresentar os serviços e produtos de forma organizada.
- Criar um portfólio visual para diferentes categorias.
- Facilitar pedidos de orçamento e contato com a empresa.
- Manter uma experiência responsiva e coerente com a identidade da marca.
